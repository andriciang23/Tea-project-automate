# Blog content plan

The Shopify blog is HojichaYa's long-tail SEO engine: informational posts capture people
researching tea, build authority, and funnel to products via internal links. Aim for
**2 posts/month**, ~800–1,200 words, each targeting one primary long-tail keyword and
linking to 2–3 relevant products.

## Format for every post

- **Title (H1):** include the keyword, make it click-worthy.
- **SEO title + meta description:** same rules as products (see `keyword-strategy.md`).
- **Intro (first 100 words):** answer the query directly (great for featured snippets).
- **Body:** subheadings (H2) using related questions; 1 image with keyworded alt text.
- **CTA / internal links:** link to the matching product(s).
- **Geo:** mention Malaysia / local context (climate, where to buy, MYR pricing) once.

## Tips

- Posts 1–3 first — they target the highest-intent "discovery → purchase" path.
- Repurpose each post into a WhatsApp/IG broadcast and an ad creative angle (cross-pillar).
- Update older posts every ~6 months (Google rewards freshness) and re-submit the sitemap.
